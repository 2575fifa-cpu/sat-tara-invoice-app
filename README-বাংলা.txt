সাত তারা জালালিয়া বস্ত্র বিতান — Android APK প্রজেক্ট

গুরুত্বপূর্ণ: এটি Android Studio-তে APK বানানোর SOURCE PROJECT; এখানে কম্পাইল করা .apk ফাইল নয়। এই পরিবেশে Android SDK/Gradle build setup নেই, তাই APK কম্পাইল/পরীক্ষা করা সম্ভব হয়নি।

যা আছে
- V12 ইনভয়েস অ্যাপের HTML/JavaScript ও ডিজাইন
- নতুন ইনভয়েস, স্বয়ংক্রিয় হিসাব, পেমেন্ট স্ট্যাটাস, PDF/প্রিন্ট, WhatsApp সারাংশ
- আগের ইনভয়েস সার্চ/লোড, দৈনিক বিক্রির হিসাব
- এই অ্যাপের ভেতরে ডেটা ব্যাকআপ/পুনরুদ্ধার বোতাম
- Android WebView wrapper, যাতে এটি আলাদা অ্যাপ আইকনসহ খোলে

APK বানানোর জন্য
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. Android Studio থেকে Open নির্বাচন করে এই ফোল্ডারটি খুলুন।
3. Gradle sync শেষ হতে দিন এবং Android SDK Platform 35 ইনস্টল করতে বললে ইনস্টল করুন।
4. Build > Build APK(s) নির্বাচন করুন।
5. APK সাধারণত app/build/outputs/apk/debug/app-debug.apk-এ তৈরি হবে।
6. APK ফোনে কপি করে ইনস্টল করুন। Android-এ প্রয়োজন হলে এই উৎস থেকে Install unknown apps অনুমতি দিন।

ডেটা সংরক্ষণ — খুব গুরুত্বপূর্ণ
- Chrome/Netlify ওয়েবসাইটের localStorage এবং APK-এর WebView localStorage আলাদা। তাই আগের ইনভয়েসগুলো APK-তে স্বয়ংক্রিয়ভাবে আসবে না।
- পুরোনো Netlify অ্যাপ খুলে ডেটা ব্যাকআপ/রপ্তানির সুবিধা নেই এমন V12 হলে, এই প্রজেক্টে থাকা ব্যাকআপ বোতাম পুরোনো সাইটে থাকবে না। আগে পুরোনো V12 HTML-এ ব্যাকআপ ফিচার যোগ করে আপলোড করতে হবে, তারপর সেখান থেকে JSON ব্যাকআপ ডাউনলোড করে নতুন APK-তে আমদানি করতে হবে।
- এই প্রজেক্টের HTML-এ ব্যাকআপ/পুনরুদ্ধার ফিচার যোগ করা হয়েছে। পুরোনো লাইভ সাইটে এখনো নেই, তাই APK ইনস্টল করার আগে পুরোনো ডেটা রপ্তানির ব্যবস্থা করতে হবে।
- APK-তে সংরক্ষিত ডেটা অ্যাপের নিজস্ব স্টোরেজে থাকবে। অ্যাপ আনইনস্টল করলে ডেটা মুছে যেতে পারে; নিয়মিত ব্যাকআপ রাখুন।

দ্রষ্টব্য: Android WebView-এর Print/PDF এবং WhatsApp লিংক বিভিন্ন Android সংস্করণে পরীক্ষা করা প্রয়োজন। এই source project build/test করা হয়নি।
